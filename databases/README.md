# Put the two database files here

This folder is empty on purpose. The databases are too big for git, so they are shared on the [Releases page](https://github.com/hesamworkshop/sql-practice-lab/releases/latest).

1. Download [`chinook-sqlite.zip`](https://github.com/hesamworkshop/sql-practice-lab/releases/latest/download/chinook-sqlite.zip) and [`employees-sqlite.zip`](https://github.com/hesamworkshop/sql-practice-lab/releases/latest/download/employees-sqlite.zip).
2. Unzip both into this folder.

When you are done it looks like this:

```
databases/
├── Chinook_Sqlite.sqlite
├── Chinook-LICENSE.txt
├── Chinook-CREDITS.txt
├── employees_db-full-1.0.6.db
├── Employees-LICENSE.txt
├── Employees-CREDITS.txt
└── README.md
```

You can keep the databases anywhere you like. This folder is just a tidy place for them, and it is where `tools/check_answers.py` looks first.
